# Sprint M4 «Доказательство ценности» — релиз-заметка (2026-08-30)

Спринт M4 закрывал главный вопрос Phase 3: **даёт ли cod-doc измеримую ценность живым проектам**, а не только проходит тесты. Ответ получен на трёх фронтах: чужой корпус документации, боевая петля ZAIrgRush и полный контур ingest AI-ревью.

## Что вошло

### 1. Orakul: 405 документов под управлением (ADO-062, ADO-064)

- Проект Orakul перерегистрирован на актуальную схему (миграции 0027/0028 на существующую БД, данные сохранены).
- Фиксы fidelity M3 верифицированы на живом корпусе: **405/405 документов, 0 stale_export, 0 missing**.
- Инцидент: массовый `--force-write` переписал авторский frontmatter (невалидный YAML падал в «расхождение»). Урон откачен за минуты; корень закрыт фиксом **ADO-064**: непарсибельный frontmatter = «не можем доказать расхождение» → verbatim. Урок зафиксирован: guard'ы деструктивных флагов читаются до конца, dry-run обязателен на массовых операциях.

### 2. E5-C: doc-context доказан в бою на OpenRouter (ADO-063)

Первый прогон петли ZAIrgRush, полностью оплаченный через OpenRouter (чистый учёт, ключ $5 с TTL 1 час):

- executor: kimi CLI → `qwen/qwen3.8-27b` через изолированный `KIMI_CODE_HOME`;
- reviewer: claude CLI → `anthropic/claude-sonnet-5` через OpenRouter Anthropic-skin.

**Результат:** задача s5dc (`format_csv_line` по конвенции из cod-doc) — **done с 1 итерации**, review approve, gate 119 тестов зелёный. Блок документа дошёл до промпта executor'а, реализация дословно следует документированной конвенции — ловушка задачи не сработала. **Стоимость прогона: $0.98.** Вердикт по RFC 22 §3.4: **масштабируем**.

Механика: `ctx docs --include-body` (cod-doc) + приоритет путей `task.doc_paths → doc_context_paths → fail-open` (ZAIrgRush).

### 3. Activity events: полный write-path (ADO-040)

- Единый helper `emit_for_write` / `write_revision_and_emit_event`: revision + activity event + run_id атомарно в одной транзакции.
- Покрытие write-сайтов: adr 6/6, approval 3/3, task_doc 2/2, story 5/5, comment 3/3, checkout 3/3, commit_link 1/1, link resolver 4/4, repo_index 1/1, doc 6/6.
- Глотание ошибок emit в task_service устранено — ошибка события теперь видна и откатывает транзакцию.

### 4. Ingest ai_review: pull-модель (SYM-009)

- `cod-doc ingest ai_review --from-pr N [--repo PATH]` — скачивает GitHub Actions artifact `pr-review-export-N` и импортирует находки с дедупликацией.
- Идемпотентный поллер `scripts/ingest-orakul-reviews.sh` (state-файл, dry-run) — готов к постановке на cron.
- Проверено в бою: 3 исторических PR-экспорта Orakul импортированы, повторная находка `no-math-round-ts` имеет `times_seen=4`, рабочее дерево Orakul не тронуто.
- Upstream: PR [Orange-hanter/ai-reviewer#5](https://github.com/Orange-hanter/ai-reviewer/pull/5) — `fp/verifierStatus/actionabilityScore` в slimFinding, `EXPORT_VERSION=2` (аддитивно). Адаптер cod-doc уже понимает v2.
