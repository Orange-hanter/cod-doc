## 3. Контракты RFC 36 §3.7

C-01…C-19 закрыты тестами задач-владельцев (столбец «Проверка до claim»).
Все они пока draft-обязательства: confirmed `doc_code_claim` появятся, когда
снимок структуры свяжет их с кодом; виды `value` и `invariant` из RFC 28
§3.4 в `CLAIM_KINDS` ещё нет. C-20/C-21 — V2 (C-20 закрыт в #269, C-21 —
ROAD-011).

## 4. На живых данных

- **Копия БД (снимок 2026-10-19 + 0054), до деплоя:** 144 открытые задачи в
  14 планах, прогноз от +1 до +7 недель; 33 открытых ребра, все внутри планов
  — подтягиваний и межплановых флагов нет, что верно.
- **Браузер на изолированном стенде:** светлая и тёмная темы, 390px без
  горизонтальной прокрутки, перестановка htmx без ошибок консоли, Timeline на
  странице `open-questions-2026-09`.
- **Гермес после деплоя `e640b57`:** все 9 проектов на 0054, у каждого плана
  ранг (94 плана). `cod-doc roadmap show -p cod-doc`: 157 открытых задач в 16
  планах, выборка 8 полных недель `[10, 14, 67, 72, 29, 12, 49, 20]`,
  предупреждение `inflow_exceeds`.

## 5. Отступления от RFC

- **Полосы — HTML в процентах, а не inline SVG (§3.5):** раскрытие плана в
  задачи без JS (`<details>`), цвета из токенов темы, разметку проверяют тесты.
  Координаты по-прежнему считает сервер (`api/web/roadmap_chart.py`).
- **ROAD-008 «reader получает 403 на POST» не реализуемо:** у веба нет ролей по
  токену (он за basic_auth Caddy). На REST/MCP `plan_move` не в `READER_TOOLS`.
- **Окно эмпирики V2 привязано к данным** (60 дней до самой свежей строки
  `task_metrics`), а не к сегодняшней дате: `sequence()` остаётся без `asof`
  (контракт C-01).

## 6. Что вскрылось по дороге

- **MCP на Гермесе отдавал 502 ~10 часов:** после деплоя `37333a9` контейнер
  `cod-doc-mcp` остался в `Created`. В README узла добавлен шаг «после `up` —
  `docker compose ps -a`, оба `Up`».
- **Метрики длительности не работали никогда** (RFC 33 F1–F3): FLW-001…003
  (#268, #270) — одно событие на переход, ревизия checkout, длительности из
  `activity_event` и идемпотентный бэкфилл. На живой БД: 538 закрытых задач,
  379 с `in_progress_hours`, 116 старше журнала событий. Это вход для V2.

## 7. Остаточный долг

- ROAD-011 (вехи) — по RFC начинать, только если планов и секций не хватит для
  ответа «когда фича пригодна».
- V3 (снимок прогноза и «прогноз сдвинулся на N дней») — задачи после опыта
  работы с V2.
- Миграции 0054 и 0055 открыли две эпохи синхронизации; сейчас с Гермесом
  ничто не синхронизируется, но реплика, которая начнёт, должна быть на 0055.
- Генерация очередей ROADMAP.md из `plan.rank` — вне скоупа RFC, кандидат.
